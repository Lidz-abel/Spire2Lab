      --output artifacts/course/proposal-20261116

    python3 -B scripts/render_course_proposal.py \
      --output artifacts/course/proposal-20261116-personalized \
      --name 'ACTUAL_NAME' --student-id 'ACTUAL_STUDENT_ID'

  This uses existing libcairo, libpango, libpangocairo, libgobject, Noto CJK fonts,
  pdfinfo and pdftotext. It does not modify the project venv or install packages.

  PDF checks cover A4/two pages, content bounds, required text, identity and ZIP CRC.
  Visual review should follow every substantive layout change:

      artifacts/course/proposal-20261116/preview
